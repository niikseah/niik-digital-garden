Pi Boy

A schedule on an e-ink display for my boyfriend and I to stay updated on each other's lives, named after the Raspberry Pi computer it runs on.

Context

This project was started more on an opportunity rather than a problem — but it does solve two problems I faced.

The two problems it solves

  • My boyfriend REFUSES to use a calendar, for reasons unknown. Right now he relies solely on his brain, which I cannot deny is impressive, but causes occasional double-booking or forgetting of plans. Pi Boy relies on Google Calendar's API, which hopefully incentivises him to proactively use a schedule and stay organised.
  • We do not actively share and update each other on our plans as it slips our minds sometimes, but we wish to do so more. Having Pi Boy will facilitate the solution to both scheduling and communication concerns.

Ingredients

  • Raspberry Pi Zero WH — the computer, and the foundation of it all
  • Mini HDMI → standard converter — HDMI output to the e-ink display
  • USB OTG cable — USB on-the-go. I still do not know what this is for
  • Original PSU, 5V / 2.5A — power supply
  • Original Zero case — a case for the computer
  • Micro SD card — where Pi Boy's apps live

Getting it running

  1. 01

    Flash the OS

    Download the Raspberry Pi Imager and write Raspberry Pi OS Lite to the micro SD card. Pre-configure Wi-Fi, SSH, and timezone in the settings gear before writing.

  2. 02

    Start from MagInkCal

    I cloned speedyg0nz/MagInkCal as the foundation for this project.

  3. 03

    Wire up Google Calendar

    Follow Google's Python quickstart, rename the downloaded JSON to credentials.json, drop it in the gcal folder, then run python3 quickstart.py.

Setting up the bot

  1. 01

    Google Cloud Developer Console — for access to the Google Calendar and Google Tasks APIs

    1. Open the Google Cloud Console and create a new project.
    2. In the API Library, enable both the Google Calendar API and the Google Tasks API.
    3. Under the OAuth consent screen tab, select External, and add your email and your partner's email as Test Users.
    4. Credentials → Create Credentials → OAuth client ID, with Desktop App as the application type.
    5. Download the JSON credential file, rename it to credentials.json, and place it in the same folder as your Python script.
  2. 02

    Shared calendar

    1. Under “My calendars”, hover your shared calendar → the three-dot icon → Settings and sharing.
    2. Scroll to Integrate calendar and copy the Calendar ID.
    3. Paste that string into the SHARED_CALENDAR_ID constant in the Python file.
  3. 03

    Telegram bot

    1. Open Telegram, search for @BotFather, and issue the command /newbot. Follow the steps to get your HTTP API token and paste it into TELEGRAM_BOT_TOKEN.
    2. To prevent random Telegram users from triggering your script, use a bot like @userinfobot to find unique numerical Telegram IDs. Paste those numbers inside the array list ALLOWED_TELEGRAM_IDS in the code.
  4. 04

    Run the script locally

    1. Open your command terminal inside the project directory and run the following to install dependencies and boot up your server daemon:
    2. pip install python-telegram-bot google-api-python-client google-auth-httplib2 google-auth-oauthlib

On that first run

Your terminal will open a browser window asking you to log into your Google Account to authorize permissions. Once authorized, a file named token.json will automatically be generated in your folder, saving your login session securely so you don't have to authenticate manually ever again.
